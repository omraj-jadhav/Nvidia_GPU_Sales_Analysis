# NVIDIA GPU Sales Analysis – Excel Dashboard

## 📊 Project Overview

This project is an **Excel-based NVIDIA GPU Sales Analysis Dashboard** created to analyze GPU sales performance, revenue, customer satisfaction, pricing, regions, sales channels, and customer segments.

The project uses **Microsoft Excel** for data cleaning, analysis, KPI calculation, Pivot Tables, Pivot Charts, and interactive dashboard visualization.

The goal of this project is to demonstrate practical **Data Analysis and Business Intelligence skills using Microsoft Excel**.

---

## 🎯 Project Objective

The main objectives of this project are:

* Analyze NVIDIA GPU sales performance
* Calculate important business KPIs
* Analyze revenue and units sold
* Compare GPU models and GPU families
* Analyze regional sales performance
* Understand sales channel performance
* Analyze customer segments
* Study GPU pricing and price premiums
* Analyze customer satisfaction
* Identify important business trends and insights
* Present the analysis through an Excel dashboard

---

## ❓ Business Questions

The analysis was designed to answer questions such as:

1. What is the total revenue generated?
2. How many GPU units were sold?
3. Which GPU models generate the highest revenue?
4. Which GPU families perform the best?
5. Which regions contribute the most revenue?
6. Which sales channels sell the most units?
7. What is the average selling price?
8. What is the average customer satisfaction score?
9. How does revenue change over time?
10. How does price premium vary across GPU models?
11. Which customer segments contribute to sales?
12. What business trends can be identified from the data?
